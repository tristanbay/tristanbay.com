A tuning file converter from my Myritone format into Scala format (and likely other formats in the future). Myritone is a tuning file format based off of [Scala format](https://www.huygens-fokker.org/scala/scl_format.html). Learn more about the project and/or download the source code [here](https://github.com/tristanbay/myritone).
